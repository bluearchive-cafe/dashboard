# resource-panel

用于管理游戏内汉化资源的控制面板页面。

## 这是什么

这是一个用于查看和管理游戏内汉化资源的网页控制面板。你可以通过它查看当前资源状态，切换部分资源开关，并将设置保存到服务器。

页面支持以下功能：

- 查看游戏文本、主线中配、图像视频三类资源的状态
- 开启或关闭对应资源
- 保存当前设置
- 查看操作说明
- 复制当前控制面板链接
- 查看诊断信息，便于排查问题

## 如何打开

线上入口使用路径填写 UID：

```text
https://dash.bluearchive.cafe/XXXXXXXX
```

将 `XXXXXXXX` 替换为游戏内获得的八位大写字母 UID。

旧版 `dash.bluearchive.cafe?uid=XXXXXXXX`、`control.bluearchive.cafe?uid=XXXXXXXX` 和 `control.bluearchive.cafe/XXXXXXXX` 链接会自动迁移到上述路径格式。

本地预览时，执行：

```text
npm run dev
```

然后使用查询参数入口打开页面：

```text
http://localhost:8080/?uid=XXXXXXXX
```

## 使用前请注意

- 页面依赖网络连接才能正常使用
- 页面会访问远程接口读取和保存配置
- 页面样式、控件与字体通过 Vite 打包，网络受限时仍可正常显示
- 如果没有提供有效的 UID，页面无法读取配置，也无法保存设置

## 页面怎么用

### 1. 打开页面后先看状态

页面打开后会自动读取当前配置，并显示三类资源的状态：

- 游戏文本
- 主线中配
- 图像视频

状态说明：

- `加载中`：正在读取数据
- `可启用`：当前资源状态正常
- `维护中`：资源可能需要更新后才能正常使用
- `未获取`：页面未能成功读取状态

建议先确认状态，再决定是否开启对应功能。

### 2. 按需切换开关

页面中有三个对应开关：

- 游戏文本
- 主线中配
- 图像视频

你可以根据需要打开或关闭它们。

### 3. 点击"保存设置"

调整完成后，点击 `保存设置`，页面会将当前开关状态提交到服务器。

保存成功时会提示：

```text
设置已保存，重启游戏后生效
```

如果保存失败，页面会弹出相应提示。

### 4. 点击"查看说明"

如果你不确定每个选项的作用，可以点击 `查看说明`。页面会弹出简要操作提示。

### 5. 点击"复制链接"

点击后，页面会尝试复制当前控制面板链接，方便你发给别人或自己留存。

链接一般类似：

```text
https://dash.bluearchive.cafe/XXXXXXXX
```

只有当前页面包含有效 UID 时，才能正确生成可分享链接。

### 6. 点击"诊断信息"

如果页面异常、状态未获取或保存失败，可以点击 `诊断信息` 查看当前环境信息，用于排查问题。

诊断信息通常包括：

- 浏览器版本信息
- 当前设备和语言信息
- 页面地址
- 资源版本信息
- 屏幕与视口尺寸

## 常见问题

### 页面提示"链接无效"

这表示当前页面地址中缺少 UID。

请检查链接是否使用以下路径格式：

```text
https://dash.bluearchive.cafe/XXXXXXXX
```

如果页面提示"UID 格式无效"，请确认 UID 严格由八位大写字母组成。

### 状态一直显示未获取

可能是以下原因之一：

- 浏览器无法访问远程 API
- 当前网络环境限制了接口访问
- 接口服务异常

### 复制链接失败

常见原因：

- 当前页面没有有效 UID
- 浏览器限制了剪贴板写入权限

### 保存设置失败

可能是以下原因之一：

- 当前网络异常
- 接口服务暂时不可启用
- 当前链接中的 UID 无效

## 给普通用户的建议

- 尽量使用别人提供的完整控制面板链接直接打开
- 修改设置前，先确认三类资源状态是否正常
- 保存成功后，按页面提示重启游戏再确认效果
- 如果遇到异常，优先查看"诊断信息"并保留当前链接

## 开发

### 环境准备

```bash
npm install
```

### 常用命令

```bash
npm run dev       # 启动 Vite 开发服务器 (localhost:8080)
npm run build     # 生产构建到 dist/
npm run preview   # 预览生产构建
npm test          # 运行全部测试
npm run lint      # ESLint 代码检查
npm run format    # Prettier 代码格式化
```

### 项目结构

- `index.html` — 页面入口
- `src/main.js` — Vite 入口模块
- `src/modules/` — JS 模块（配置、网络、状态、对话框等）
- `src/lib/uid-routing.js` — UID 路由解析
- `src/css/` — 样式文件
- `src/icons/` — SVG 图标
- `public/` — 静态资源
- `tests/` — Vitest 测试
